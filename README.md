# GayGram Desktop

![GayGram Logo](.github/GayGram.png)

[ English  |   [简体中文](README-ZH.md) ]

*A bosom friend afar brings a distant land near.*

**GayGram Desktop** is a third-party Telegram client for Windows, forked from
[AyuGram Desktop](https://github.com/AyuGram/AyuGramDesktop) and based on
[Telegram Desktop](https://github.com/telegramdesktop/tdesktop) 7.0.9.

GayGram Desktop is not affiliated with Telegram Messenger LLP or the AyuGram project.

## Features

- Full ghost mode (flexible)
- Messages history
- Anti-recall
- Font customization
- Streamer mode
- Local Telegram Premium
- Translator
- Enhanced appearance

## Downloads
