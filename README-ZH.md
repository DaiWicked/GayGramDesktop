# GayGram Desktop

![GayGram Logo](.github/GayGram.png)

[ [English](README.md)  |  简体中文 ]

*海内存知己，天涯若比邻。*

**GayGram Desktop** 是一个仅面向 Windows 的第三方 Telegram 客户端，fork 自
[AyuGram Desktop](https://github.com/AyuGram/AyuGramDesktop)，基于
[Telegram Desktop](https://github.com/telegramdesktop/tdesktop) 7.0.9。

GayGram Desktop 与 Telegram Messenger LLP 及 AyuGram 项目均无隶属关系。

## 功能

- 完整的幽灵模式（可灵活配置）
- 消息历史记录
- 反撤回
- 字体自定义
- 主播模式
- 本地 Telegram Premium
- 翻译器
- 外观增强
